# 知识库使用指南

> 本文件位于 `plugins/aoi/docs/guides/`，与知识库正文 `plugins/aoi/docs/knowledge-base/` 分离。

> 工程：Project_Aether  
> 知识库路径：`plugins/aoi/docs/knowledge-base/`

## 已启用的 Cursor 配置

| 文件 | 作用 |
| --- | --- |
| `.cursor/rules/knowledge-base.mdc` | 每次对话优先检索知识库 |
| `.cursor/skills/knowledge-base-search/SKILL.md` | 检索步骤与引用格式 |
| `.cursorignore` | 忽略构建产物，**不**忽略 `docs/` 知识库 |
| `plugins/aoi/docs/knowledge-base/_index.md` | 条目目录 |

## 日常提问示例

```
按知识库回答：我们 C++ 类命名有什么要求？
```

```
请查知识库和当前文件，这段代码是否符合规范。
```

## 新增文档

1. 复制 `.md` 到 `plugins/aoi/docs/knowledge-base/<分类>/`
2. 更新 `_index.md` 表格
3. 可说：「已将 xxx 加入知识库，请更新索引后回答」

## 与 doc-maintenance-kit 重新部署

- 重新运行 `setup.bat` 会更新 `.cursor` 工具链模板，不会删除 `knowledge-base/` 下已有正文（同名导入文件除外）
