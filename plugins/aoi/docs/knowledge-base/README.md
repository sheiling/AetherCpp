# 私有知识库

本目录存放**团队/个人规范与笔记**，供 Cursor Agent 在回答前检索。

## 目录建议

```
knowledge-base/
├── _index.md          ← 条目目录（必维护）
├── cpp/               ← 语言规范
├── 相机/              ← 相机厂商 SDK 开发说明（海康、大恒等）
├── 运控卡/            ← 运动控制卡 API 手册（雷赛等）
├── process/           ← 流程与制度
└── notes/             ← 其它笔记
```

## 添加一篇文档

1. 将 `.md` 放入合适子目录
2. 编辑 `_index.md`，增加一行（id、标题、path、tags、一句话摘要）
3. 在 Agent 中可说：「已更新知识库，请按 knowledge-base Rule 回答」

## 与 SOP / 设计方案的区别

| 类型 | 位置 | 用途 |
| --- | --- | --- |
| 知识库 | `knowledge-base/` | 编码规范、通用流程、可复用经验 |
| SOP | 由部署生成的 SOP 描述/操作手册 | 某软件系统的现场操作 |
| 设计方案 | 由部署生成的设计文档 | 某软件系统的架构 |

不要把现场操作步骤写进知识库，除非 deliberately 作为通用模板。

详细说明见同工程 `guides/知识库使用指南.md`（若已部署 doc-maintenance-kit）。
