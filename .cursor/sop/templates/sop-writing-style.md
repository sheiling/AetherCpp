# 软件操作 SOP — 写作风格（面向现场）

> 适用于：`plugins/aoi/docs/AOI 检测软件 SOP描述.txt`、  
> `plugins/aoi/docs/AOI 检测软件 软件操作SOP.md` 及 AI 增量维护时的正文改写。  
> **AOI 检测软件 设计方案.md 不受本约束**（可保留架构/接口术语）。  
> **`AOI 检测软件 软件操作SOP.md` 另须遵守** `sop-output-constraints.md`（正文字眼、插图编排、富文本版式）。

---

## 读者与语气

| 读者 | 说明 |
| --- | --- |
| **操作员** | 按步骤点按钮、看日志、报异常；不需要懂程序结构 |
| **现场工艺 / FAE** | 会调参数、换型、联机验证 |
| **非读者** | 软件研发 — 细节写在 **设计方案**，不要写进操作 SOP |

**语气**：工业现场作业指导书。短句、祈使句、一步一事。禁止宣传语、口语、论文式长段。

---

## 操作步骤怎么写

1. **一步一个动作**：「点击 **保存**」，不要写「完成参数持久化后触发保存链路」。
2. **用界面上的字**：按钮、菜单、页签与 UI 一致。
3. **判定要可观察**：「保存成功且无报错」「首件 SN 为 OK」。

---

## 禁止或须转写的用语

| 避免 | 改为（示例） |
| --- | --- |
| JSON / schema / Controller / Handler | 「配置文件」「后台」 |
| SQLite / 表名 / ORM | 「软件自动保存修改记录」 |
| 挂钩 / 链路 / dispatch / 落盘 | 「保存后生效」「保存时自动记录」 |
| 后台审计、DTO | 「软件自动记录」 |

**允许保留**（现场常用）：Gerber、DXF、阈值、OK/NG、SN、MES、载台、飞针、微针 等。

---

## 全书版式（AOI 检测软件 软件操作SOP.md）

- **封面**：文档名称、适用系统、版本、生效日期、审批栏
- **文档说明** + **目录**（链到全部章节）
- 见 `sop-document-template.md`

---

## SOP 描述.txt 专用

- 可含配置键名，但须写 **「操作手册中应写为：……」**
- **必须写清**：流程与验证，不写类名除非 FAE 必须编辑该文件

---

## AOI 检测软件 软件操作SOP.md 专用（详见 sop-output-constraints.md）

- 正文中不写「UI截图」「SOP描述.txt」「设计方案.md」等维护用语；插图路径可含 `UI截图/` 目录名，图注用「页面插图」。
- 多图可同节；可用表格、强调色、符号、公式、Mermaid 等（步骤仍须简短可执行）。
