# 软件操作 SOP — 全文档结构模板



> 生成或全量同步 `plugins/aoi/docs/AOI 检测软件 软件操作SOP.md` 时**必须先搭骨架**，再按 `page-sop-template.md` 填各页。  

> **成品约束**：`sop-output-constraints.md`（正文字眼、插图编排、版式）。  

> 单页增量更新时：若缺封面/目录则补全；增删 `###` 页面后**同步更新目录**。

## 2. 目录维护规则



| 时机 | 动作 |

| --- | --- |

| 首次生成 | 封面 + 文档说明 + **完整目录** 后再写正文 |

| 增删页面 | 同步更新目录行 |

| 锚点 | 以 Cursor/VS Code 预览可跳转为准 |

## 3. 禁止



- ❌ 无封面、无目录直接写正文（除非用户明确要求极简版）

- ❌ 目录与章节编号不一致

- ❌ 在 `AOI 检测软件 软件操作SOP.md` 正文中写出 `UI截图`、`SOP描述.txt`、`设计方案.md` 等维护用语（见 `sop-output-constraints.md`）
