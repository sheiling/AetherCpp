# 软件操作 SOP（AOI 检测软件 软件操作SOP.md）— 输出约束

> **仅约束** `plugins/aoi/docs/AOI 检测软件 软件操作SOP.md` 的**正文与版式**（面向操作员/FAE 的成品）。  
> **不约束** `AOI 检测软件 SOP描述.txt`、`AOI 检测软件 设计方案.md`、`.cursor/` 内维护文件 — 维护时仍可使用真实文件名与「UI 截图」等术语。

生成或增量同步操作手册前，Agent **必须**与本文件及 `sop-writing-style.md` 一并阅读。

---

## 1. 正文中禁止出现的字眼

在 `AOI 检测软件 软件操作SOP.md` 的标题、封面、文档说明、目录、正文、变更记录、自检清单等**读者可见处**，**不得**出现下列字样（含变体、英文对照说明）：

| 禁止 | 可改用（示例） |
| --- | --- |
| `UI截图`、`UI 截图` | **页面插图**、**界面示意图**、**本页插图** |
| `SOP描述.txt`、`SOP 描述`、`SOP描述` | **页面清单**、**本手册章节**（不提维护用文件名） |
| `设计方案.md`、`设计方案`、`设计文档`（指研发架构文件时） | **研发技术说明**、**内部设计资料**（不写出 `.md` 文件名） |
| `真相源`、`_index.md`、`incremental-sop-doc` 等维护用语 | 不写；仅维护侧使用 |

**允许**：Markdown **图片路径**可指向 `UI截图/` 目录，例如：

```markdown
![主页界面](./UI截图/主页.png)
```

- 路径中的目录名（如 `UI截图`）**可以保留**，便于仓库统一存放。
- **图片 alt / 图注**用页面名或「图 1-1 主页」，不要用「UI截图」作说明文字。

---

## 2. 插图与章节结构（灵活编排）

- **不必**「一页一图、一节一图」机械套用 `page-sop-template.md`。
- **可以**：多张插图放在**同一小节**（同一功能、同一流程、同一弹窗前后对比、同一配置区多 Tab 等）。
- **可以**：先写步骤再在步骤中穿插插图，或先用「#### 页面插图」集中展示再写操作步骤。
- **可以**：无插图仅文字（信息不足标「待补充项」），但不得虚构界面。
- 插图与文字冲突时，以**页面插图**为准（维护侧仍以 `plugins/aoi/docs/UI截图/` 文件为事实来源）。

单页仍建议覆盖（可合并小节）：页面目的、适用角色、前置条件、核心功能、详细操作步骤（通常 ≥8 步）、结果判定、常见误区（≥3）、异常处理（≥3）。结构见 `page-sop-template.md`（**参考**，非每张图一条）。

---

## 3. 版式与表达（不限于纯文字）

在符合 `sop-writing-style.md`（现场用语、禁止研发词写进步骤）的前提下，**鼓励**丰富版式：

| 类型 | 用法 |
| --- | --- |
| **表格** | 参数对照、灯色含义、按钮状态、检查项清单 |
| **强调** | `**加粗**`、必要时 HTML `<span style="color:…">` 或 `<mark>`（导出 Word/PDF 时视工具支持） |
| **背景/提示块** | Markdown 引用 `>` 作注意/警告；或 HTML `<div style="background:…">` |
| **符号** | ✅ ❌ ⚠️ 🔴 🟢 等（适度，勿喧宾夺主） |
| **公式** | LaTeX `$...$` / `$$...$$`（阈值、换算） |
| **流程图** | Mermaid `flowchart` / `sequenceDiagram` |
| **形状示意** | Mermaid、ASCII 框图、表格模拟布局 |

**禁止**：为炫技堆版式导致操作员难扫读；步骤仍须**短句、一步一事**。

## 4. 全书骨架（不变）

仍须遵守 `sop-document-template.md`：**封面**、**文档说明**、**目录**、正文 §0～§N、**变更记录**、**自检清单**。  
文档说明中不写 `AOI 检测软件 SOP描述.txt` / `AOI 检测软件 设计方案.md` 文件名；可写「与研发技术说明勿混读」「操作以界面与页面插图为准」。
