> 面向向上汇报：本文汇总从立项到当前（2026-06）在**代码层面**完成的工作、架构落点、**开发约定**与待办边界。

## 一、交付概览

| 维度 | 结论 |
|------|------|
| **插件定位** | 强制启用（`Required: true`），提供 RBAC 配置管理 + 全局运行时权限服务 |
| **数据后端** | Mock（开发对照）/ SQLite（默认验收）/ MySQL（可切换）；SQL 真源在 `config/sql/` |
| **运行时模型** | `PermService` + DB grants；未登录 ≡ 最小用户；超级用户全量授权 |
| **管理端** | 用户 / 角色 / 权限资源 / 审计日志 四页 MVVM 闭环 |
| **审计** | Command 全局中间件自动落库 + 登录/登出/超时手动落库 |
| **完成度** | 插件内 + B0～B5（37/41）已完成；**B6 业务插件纳管未开始** |

一句话：**权限插件自身已可独立验收；其它业务插件的 nav/sub/action 资源与 Command 绑定仍待 B6 分期接入。**

## 三、分阶段代码改动清单

### 3.1 阶段 1～2：规范与数据库

| 改动 | 说明 |
|------|------|
| **三级资源模型** | `perm_permission.resource_type`：`nav` / `sub_page` / `action`；废弃旧 `kind` + `module` |
| **全局唯一 key** | `perm_permission.key` UNIQUE；运行时 `PermService::can(key)` 只认 key |
| **Schema** | `config/sql/sqlite|mysql/001_schema.sql`：6 张表（user/role/permission/user_role/role_permission/audit_log） |

### 3.5 数据持久化（Mock → SQLite/MySQL）

| 改动 | 说明 |
|------|------|
| SQL 真源迁移 | `plugins/permission/data/sql/` → **`config/sql/{sqlite|mysql}/`** |
| 路径解析 | `repository/orm/permission_sql_paths.*`：Debug 优先项目根 `config/sql` |
| 种子幂等 | `repository/orm/data_seeder.cpp`：按表空/标记判断，事务包裹，避免重复插入 |
| 存储切换 | `permissionplugin.cpp`：`kUseMysqlStorage` 开关；默认 SQLite `data/permission.db` |
| 启动同步 | `orm_data_store.cpp`：`syncSuperAdminGrantsFromCatalog()` 打开库时同步超级角色全量授权 |
| 构建同步 | `plugins/permission/CMakeLists.txt` POST_BUILD 拷贝 `config/sql` 到 exe 目录 |

**SQLite 种子规模**（`003_seed_permissions.sql`）：

- 33 条 `perm_permission`（1 nav + 4 sub_page + 28 action，与 `perm_action_keys.h` 一致）
- 2 角色 + 2 用户（`002_seed_users.sql`，固定 id 1/2）
- `super_admin` 种子脚本内全表授权 + **每次 open 自动 `syncSuperAdminGrantsFromCatalog()`**
- `minimal` 种子 **11 条**授权（nav+四子页+用户查询/重置筛选+审计查询/重置/翻页）

**种子幂等**（`repository/orm/data_seeder.cpp`）：

| 脚本 | 完成判定 | 半拉子库 |
|------|----------|----------|
| `002_seed_users.sql` | `super_admin`+`minimal` 角色存在且 `admin`+`minimal` 用户存在 | 表有数据但未完成 → **拒绝**并提示清表 |
| `003_seed_permissions.sql` | 存在 `nav.permission` 且两角色均有 `perm_role_permission` 行 | 同上 |

执行在**单事务**内；已完成则 `qDebug` 跳过，不重复 INSERT。

**SQL 路径**：`permission_sql_paths.cpp`；Debug 优先项目根 `config/sql`，否则 `{exe}/config/sql`。

**超级管理员同步**（`role_model.cpp::syncSuperAdminGrantsFromCatalog`）：

- 将 catalog 全部 `perm_permission.id` 写入 `super_admin` 的 `perm_role_permission`
- 触发：`OrmDataStore::open()` 成功后；权限资源 CRUD/启停后
- catalog 非空时同步失败 → `open()` 失败，阻止带病启动

### 3.6 审计日志框架

#### common/mvvm（框架层，与 Permission 解耦）

| 文件 | 职责 |
|------|------|
| `command_audit_registry.h/.cpp` | `CommandAuditEvent` / `ManualAuditEvent`；全局回调注册 |
| `auditcommandmiddleware.h/.cpp` | `Command::run()` post 阶段发射审计事件 |
| `command.cpp` | 有回调时：全局审计 → 实例管道 → `execute()` |

#### Permission 插件（落库实现）

| 文件 | 职责 |
|------|------|
| `service/audit_log_writer.h/.cpp` | `registerCallbacks()`；`appendCommandAudit` / `appendManualAudit`；登录成败 |
| `permissionplugin.cpp` | `initialize` 注册回调；空闲超时手动审计 |
| `plugins/core/mainwindow.cpp` | 主动登出手动审计 |
| `ui/vm/login_view_model.cpp` | 登录成功/失败审计 |

**过滤规则**（`audit_log_writer.cpp::shouldSkipCommand`，后缀匹配不区分大小写）：

| 跳过条件 | 说明 |
|----------|------|
| 命令名为空 | 未 `setName` 的 Command 不审计 |
| 以 `.query` 结尾 | 如 `perm.users.query` |
| 以 `.prevPage` 结尾 | 如 `perm.audit.prevPage` |
| 以 `.nextPage` 结尾 | 如 `perm.audit.nextPage` |
| 以 `.resetFilter` 结尾 | 如 `perm.users.resetFilter` |
| 以 `.selectAll` 结尾 | 如 `perm.roles.selectAll` |
| 以 `.clear` 结尾 | 如 `perm.roles.clear` |

**会落库的 Permission 写操作示例**：`perm.users.create`、`perm.roles.save`、`perm.roles.reset`、`perm.audit.export` 等。

**已知缺口**：`perm.resources.save/reset` 的 Command 未 `setName`，当前无 Command 审计。

**已知局限**（P6 未落地）：Command 路径 `result` 仅区分 `cancelled` / `success`，**不反映**业务 `OperationResult.ok`；`detailJson` 暂为轻量元数据。

| 表 | 用途 | 关键考量 |

## 八、开发约定汇总（汇报用「规范清单」）

| 类别 | 约定要点 |
|------|----------|
| **资源模型** | 三级：`nav` / `sub_page` / `action`；废弃 `module`、`kind` |
| **key** | 全局唯一；`nav.*` / `sub.*` / `perm.*`；titleKey 与 `perm_permission.key` 一致 |
| **运行时** | 仅 `PermService::can(key)`；未登录 ≡ `minimal`；单用户单角色 |
| **Command** | `bindCommand`→`run()`；有 `setName` 则 `canExecute` 查 PS；登录 Command 无 name |
| **normalize** | 保存授权前剔除无祖先、disabled、非法 parent 的 id |
| **实体保护** | `super_admin`/`admin` 隐藏且不可删；`minimal` 可改 grants 不可删 |
| **审计过滤** | 6 后缀 + 空 name 跳过；见 §3.6 表 |
| **审计手动** | `auth/login`、`login_failed`、`logout`、`idle_timeout_logout` |
| **种子** | 幂等检测；半拉子拒绝；`super_admin` open 时全量同步 |
| **不做** | Command Middleware 二次鉴权；设备启动审计 |

完整说明与接入步骤见 **`user_guide.md` 第十一章**。
